# BMI Calculator

This is a simple BMI Calculator made using HTML, CSS and JavaScript.

It takes height (in meter) and weight (in kg) from the user and calculates BMI.

## How It Works

BMI Formula:

BMI = Weight / (Height × Height)

After calculation:
- If BMI < 18.5 → Underweight
- If BMI between 18.5 and 24.9 → Normal
- If BMI ≥ 25 → Overweight

The result is shown on the screen.

## Technologies Used

- HTML (Structure)
- CSS (Basic Styling)
- JavaScript (Calculation & Logic)

## How to Run

1. Download the project
2. Open index.html in browser
3. Enter height and weight
4. Click Calculate


Note: Currently this project is not fully responsive for mobile devices.
